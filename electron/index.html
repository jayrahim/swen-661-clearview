Keyboard shortcuts

Use these shortcuts from anywhere in the desktop prototype.

⌘/Ctrl + 1–5
Open Home, Visits, Messages, Records, or Settings
⌘/Ctrl + K
Focus search
⌘/Ctrl + /
Open this shortcut reference
Esc
Close an open dialog or menu
Tab
Move through controls in reading order
Enter / Space
Activate the focused control
